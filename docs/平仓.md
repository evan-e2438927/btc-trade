## 1. 什么是平仓

**平仓**（Close Position）是指**卖出你持有的资产，结束当前持仓**的操作。

### 通俗类比

> 你买了一套房子（开仓），现在把它卖出去（平仓）。  
> 卖出的那一刻，你的盈亏才真正"落袋为安"——之前的涨跌都只是"纸面盈亏"。

在现货交易中：

```
开仓：用 USDT 买入 BTC  →  持有 BTC（有持仓）
平仓：把 BTC 卖出换回 USDT  →  持仓归零（空仓）

平仓 = 卖出 BTC = 结束持仓
```

---

## 2. 开仓 vs 平仓

| 操作 | 方向 | 含义 | 结果 |
|------|------|------|------|
| **开仓**（Open） | 买入 | 建立持仓，开始持有 BTC | BTC ↑，USDT ↓ |
| **平仓**（Close） | 卖出 | 结束持仓，卖回 USDT | BTC ↓，USDT ↑，盈亏确定 |

```
时间轴：

买入 0.1 BTC @ 60000          卖出 0.1 BTC @ 65000
        │                               │
        ▼                               ▼
      开仓                            平仓
   持仓: 0.1 BTC               持仓: 0 BTC（空仓）
   均价: 60000                  实现盈亏: +500 USDT
        │                               │
        └────────── 持仓中 ─────────────┘
              浮动盈亏: (65000-60000)×0.1 = +500（纸面）
```

## 3. 平仓方式

### 3.1 市价平仓

以当前市场价格**立即卖出**，成交快速但价格不可控。

```
持仓：0.1 BTC，均价 60000
当前价：65000

点击"市价平仓" → 立即以 65000 卖出 0.1 BTC
收回：65000 × 0.1 = 6500 USDT
盈利：6500 - 6000 = +500 USDT ✅
```

**适用场景**：急需快速离场，不在意几十美元的价格波动。

### 3.2 限价平仓

设置一个**目标卖出价格**，等价格到达时再成交。

```
持仓：0.1 BTC，均价 60000
当前价：65000，你认为还能涨到 67000

挂限价卖单 @ 67000 → 等待价格上涨到 67000 再成交
若价格涨到 67000：收回 6700 USDT，盈利 +700 USDT ✅
若价格未涨到 67000：订单一直挂着，未平仓 ⏳
```

**适用场景**：希望在更高价位锁定利润，接受等待风险。

---

## 4. 部分平仓 vs 全部平仓

| 类型 | 说明 | 结果 |
|------|------|------|
| **全部平仓** | 卖出所有持仓 BTC | 持仓归零，完全退出市场 |
| **部分平仓** | 只卖出持仓的一部分 | 仍持有剩余 BTC，继续参与行情 |

```
持仓：0.1 BTC

全部平仓：卖出 0.1 BTC → 持仓 = 0（空仓）
部分平仓：卖出 0.05 BTC → 持仓 = 0.05 BTC（仍持有）
```

**部分平仓的意义**：
- 锁定一部分利润，降低风险
- 保留另一部分仓位，继续享受潜在涨幅
- 常见于止盈策略中（"先落袋一半"）

## 5. 平仓后的盈亏计算

### 已实现盈亏（Realized PnL）

平仓之后，盈亏从"浮动"变为"已实现"，计入最终收益：

$$
\text{已实现盈亏} = (\text{平仓价} - \text{均价}) \times \text{平仓数量}
$$

**举例：**

| 情况 | 均价 | 平仓价 | 数量 | 盈亏 |
|------|------|--------|------|------|
| 盈利平仓 | 60000 | 65000 | 0.1 BTC | +500 USDT |
| 亏损平仓 | 60000 | 58000 | 0.1 BTC | −200 USDT |
| 保本平仓 | 60000 | 60000 | 0.1 BTC | 0 USDT |

### 与浮动盈亏的区别

| 类型 | 状态 | 是否真实到账 |
|------|------|------------|
| **浮动盈亏**（Unrealized PnL） | 持仓中（未卖出） | ❌ 纸面盈亏，可能随价格变化 |
| **已实现盈亏**（Realized PnL） | 平仓后 | ✅ 真实到账，不再变化 |

---

## 6. 手动平仓 vs 自动平仓

| 类型 | 触发方式 | 说明 |
|------|---------|------|
| **手动平仓** | 用户主动操作 | 在交易面板点击卖出，自行判断时机 |
| **止损平仓** | 价格下跌自动触发 | 设置止损价，价格跌到该价时系统自动卖出，防止亏损扩大 |
| **止盈平仓** | 价格上涨自动触发 | 设置止盈价，价格涨到该价时系统自动卖出，锁定利润 |

```
         止损区          开仓价          止盈区
    ─────────┼──────────────┼──────────────┼─────
         58000          60000          65000

价格向下穿越 58000 → 止损平仓（自动）
价格向上穿越 65000 → 止盈平仓（自动）
其他时间可随时手动平仓
```

## 7. 本系统中的平仓实现

### 手动平仓

用户在 `TradingPanel` 发起卖出操作，与普通卖单完全相同：

```typescript
// POST /api/orders
{
  side: 'sell',
  type: 'market',   // 或 'limit'
  quantity: 0.1     // 平仓数量
}
```

`fillOrder` 执行后：
- `positions.quantity` 减少
- `accounts.BTC.available_balance` 减少
- `accounts.USDT.available_balance` 增加

### 自动平仓（止损/止盈子单）

市价单或限价单成交时，若用户设置了止损/止盈，系统调用 `createCloseOrder` 自动创建**平仓子单**（`is_close_order = true`）：

```
原始买单成交（0.1 BTC @ 60000）
    │
    ├─ [有止损设置] → 创建止损子单
    │    stop_price = 58000
    │    side = 'sell'
    │    quantity = 0.1
    │    is_close_order = true   ← 标记为平仓单
    │
    └─ [有止盈设置] → 创建止盈子单
         take_profit_price = 65000
         side = 'sell'
         quantity = 0.1
         is_close_order = true
```

订单引擎（每 500ms 轮询）检测到触发条件后自动执行成交：

```typescript
// server.js 引擎触发逻辑
// 止损：价格下跌触发
if (order.stop_price && currentPrice <= order.stop_price) {
  await fillOrderInEngine(order, currentPrice);
}

// 止盈：价格上涨触发
if (order.take_profit_price && currentPrice >= order.take_profit_price) {
  await fillOrderInEngine(order, currentPrice);
}
```

### 防止平仓子单再创建子单（防递归）

`is_close_order = true` 的订单成交后，引擎不会再为其创建新的止损/止盈子单：

```typescript
// 只有原始订单（非平仓子单）成交后，才创建子单
if (!order.is_close_order) {
  if (order.stop_price) await createCloseOrder('sl', ...);
  if (order.take_profit_price) await createCloseOrder('tp', ...);
}
```

### 平仓后的持仓更新

```typescript
// fillOrder 中的持仓更新逻辑
if (side === 'sell') {
  const newQty = position.quantity - quantity;

  if (newQty <= 0) {
    // 全部平仓：持仓归零
    position.quantity = 0;
    position.entry_price = 0;
    position.unrealized_pnl = 0;
  } else {
    // 部分平仓：持仓减少，均价不变
    position.quantity = newQty;
    // entry_price 不变
  }
}
```

## 总结

```
平仓 = 卖出持有的 BTC，结束持仓，盈亏落袋为安

平仓方式：
  ├── 手动平仓（主动卖出）
  ├── 止损平仓（价格下跌，自动触发，防亏损扩大）
  └── 止盈平仓（价格上涨，自动触发，锁定利润）

平仓规模：
  ├── 全部平仓（持仓归零）
  └── 部分平仓（仍有剩余持仓）

本系统实现：
  ├── 手动：普通 sell 订单
  └── 自动：is_close_order=true 的止损/止盈子单，引擎轮询触发
```
