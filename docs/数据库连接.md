| 参数 | 值 |
|------|-----|
| Host | `192.168.0.105` |
| Port | `5432` |
| Database | `mydb` |
| User | `postgres` |
| Password | `admin` |

---

**命令行连接（psql）：**
```
psql -h 192.168.0.105 -p 5432 -U postgres -d mydb
```

**常见客户端（TablePlus / DBeaver / DataGrip）：** 填入上面的参数即可。
