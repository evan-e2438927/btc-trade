# Requirements

**需求**: 增加一个切换K线时间周期的下拉选择器
**迭代**: 002-chart-interval-feature
**类型**: feature
**日期**: 2026-03-27

---

## R-001: K线时间周期下拉选择器

**描述**: 在 K线图组件中添加时间周期下拉选择器，支持切换不同的时间周期（1m, 5m, 15m, 30m, 1H, 2H, 4H, 1D 等）。

**验收标准**:
- [ ] 页面加载时默认显示 15 分钟周期（下拉默认选中 15m）
- [ ] 下拉列表包含常用周期：1m, 5m, 15m, 30m, 1H, 2H, 4H, 1D
- [ ] 切换周期后，图表立即重新加载为新周期
- [ ] 下拉样式与现有 UI 风格一致（深色主题）
- [ ] 下拉组件放置在 K线图右上角或标题区域

**当前状态**:
- TradingView widget 的 `interval: '15'` 是硬编码在 `createWidget` 函数中的
- widget 创建后 interval 不可动态修改，需销毁重建

**置信度**: 高 (0.9) [✅ 已确认]
**⚠️ 假设**: 下拉选项为 1m, 5m, 15m, 30m, 1H, 2H, 4H, 1D 共 8 个

---

## R-002: 周期切换交互体验

**描述**: 切换周期时，用户应能直观看到图表正在重新加载。

**验收标准**:
- [ ] 切换期间有加载指示（可选，利用 TradingView 内置 loading）
- [ ] 图表切换流畅，无明显闪烁或长时间白屏

**置信度**: 中 (0.7) [⚠️ 假设: TradingView widget 自身处理 loading]

---

## R-003: 周期状态持久化（可选）

**描述**: 用户切换周期后刷新页面，希望保持上次选择的周期。

**验收标准**:
- [ ] 使用 localStorage 记住用户上次选择的周期
- [ ] 页面刷新后恢复之前的选择

**置信度**: 低 (0.5) [⚠️ 假设: localStorage 持久化]
